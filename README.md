# Portfolio Website

My personal portfolio site. Built with plain HTML, CSS, and JavaScript — no frameworks, no nonsense.

**Live at:** [showmikbhowmik.github.io/portfolio](https://showmikbhowmik.github.io/portfolio/)

## What's in here

- **index.html** — main page structure (and the intro/hero canvas animations)
- **styles.css** — all the styling and animations
- **Showmik_Resume.pdf** — the resume both Resume buttons point at (re-upload whenever it changes)
- **favicon.svg** — browser tab icon

## Sections

- "Who's watching?" profile picker + intro
- Hero / stat tiles
- Relevant Professional Experience (Vira AI, LAPP Insulators, Worldwide Electric, RIT)
- Projects (VisionVoice, Transcendent, Gesture-Jutsu)
- Skills
- Leadership (Resident Advisor)
- Education
- About / Contact

## Running locally

Just open `index.html` in a browser. That's it.
